O que eu faço?

Como Web Developer, eu trabalho com essas duas principais Linguagens:

HTML

HTML é a linguagem de marcação usada para criar a estrutura e o conteúdo de páginas da web. Ele define elementos como títulos, parágrafos, imagens e links.

CSS

CSS é a linguagem de estilo usada para controlar a aparência visual das páginas da web, definindo cores, fontes, layouts e outros aspectos visuais.
